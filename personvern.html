Personvern

ltj-production behandler personopplysninger du selv sender inn via kontaktskjemaet, typisk navn, virksomhet, e-post, telefon og innholdet i meldingen.

Opplysningene brukes for å svare på henvendelsen, vurdere behovet ditt og følge opp eventuell dialog om nettside, nettsidesjekk eller retting. Behandlingsgrunnlaget er berettiget interesse i å kunne svare på henvendelser og eventuelt forberede en avtale.

Skjemaet sendes via Formspree, som fungerer som teknisk leverandør for innsendingen. Ikke send sensitive personopplysninger gjennom skjemaet.

Opplysningene lagres ikke lenger enn nødvendig for å følge opp henvendelsen. Du kan be om innsyn, retting eller sletting av opplysninger som gjelder deg.

Nettsiden bruker ikke analyse- eller markedsføringscookies i denne løsningen. Dersom dette endres, skal siden oppdateres med tydelig informasjon om formål og samtykke.
