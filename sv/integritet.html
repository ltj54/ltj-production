Integritetspolicy

ltj-production behandlar de personuppgifter som du själv skickar via kontaktformuläret, vanligtvis namn, företag, e-postadress, telefonnummer och innehållet i meddelandet.

Uppgifterna används för att besvara förfrågan, bedöma dina behov och följa upp eventuell dialog om webbplats, webbplatskontroll eller ändringar. Den rättsliga grunden är ett berättigat intresse av att kunna besvara förfrågningar och vid behov förbereda ett avtal.

Formuläret skickas via Formspree, som är teknisk leverantör för inskickningen. Skicka inte känsliga personuppgifter via formuläret.

Uppgifterna sparas inte längre än vad som behövs för att följa upp förfrågan. Du kan begära tillgång till, rättelse eller radering av uppgifter som gäller dig. Använd kontaktformuläret på startsidan för att skicka en begäran.

Webbplatsen använder inte analys- eller marknadsföringskakor i den här lösningen. Om det ändras ska webbplatsen uppdateras med information om syfte och samtycke.
